## The GUI installer — `dist/SkeletonKey-Setup.*`

`SkeletonKey-Setup.vbs` (flash-free launcher) → `powershell -WindowStyle Hidden -File
SkeletonKey-Setup.ps1` (WinForms). Same pattern/theme as Ven's Legacy Downloader. `.bat` calls
the `.vbs`. `install.bat` / `uninstall.bat` are the CLI fallback (they prompt for the game
folder; also take it as arg 1).

Current features: finds/browses the game folder (remembers it in
`%LOCALAPPDATA%\SkeletonKey\gamefolder.txt`), live status (genuine runtime / already installed
/ not-the-runtime / no legacy.exe + config.xml fullscreen state), one-click Install / **Update**
(re-copies the shim) / Uninstall, best-effort Kinect-Runtime detection (`Test-KinectRuntime`
scans installed-programs registry) shown as a link that doubles as the download link, a
**Gestures** button that shows `gestures.png` (text fallback), a HUD checkbox that currently
only writes `overlay = 1` **on Install**.

## Gesture pictograms — `docs/pictos/` (done, v13)

Rendered headless from the JD "picto" stickman rig (`pictomodel_jdhelper/jdhelper/model.blend`,
a local download — not in this repo) with Blender 5.2, `--background --python`. 7 stills (`ready/right/left/up/down/confirm/back.png`, trimmed
transparent) + `gesture-sheet.png` (composite, HUD-coloured labels). `dist/gestures.png` = the
sheet (bundled in the zip, shown by the GUI Gestures button). README + `SETUP.md` §3 embed it.

Final pose script: **`scratchpad/pose_render_v13.py`** (13 iterations + one Gemini refinement
pass). Key facts if they need re-rendering:
- **MIRRORED** — the figure gestures with its LEFT hand (`.L`); JD players mirror pictos, so a
  mirroring user lands on their RIGHT hand = what the recogniser tracks. Off arm = figure's RIGHT.
- Hybrid: folded arms (READY active, CONFIRM/BACK gate) in **FK** (elbow planted); reaches in
  **IK** to rig-measured targets, then `straighten()` / `straighten_fk()` point the hand down
  the solved `ORG-forearm.*.vector`.
- Rig gotchas: FK/IK is `pb["MCH-upper_arm_parent.L"]["IK/FK"]` (1=FK, 0=IK);
  `["IK_Strertch"]=0` stops stretch (rig's typo); use `pose_bone.matrix` not `.location`.
- Recolour: `MixRGB` blend `COLOR` before each Emission Color input. Corrective Smooth on
  `Cube` MUST stay mild (factor 0.4, iters 14 — high values collapse the limbs).
