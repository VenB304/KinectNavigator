## What this project is

**Skeleton Key** = a hands-free Kinect v1 menu-navigation layer for the *Just Dance
Legacy Offline PC* mod. It ships as a drop-in `Kinect10.dll` proxy:

- Our `Kinect10.dll` (x86, `/MT`) exports 8 ordinals (5, 6, 9, 16, 17, 21, 22, 26) and
  forwards everything to the renamed genuine runtime `Kinect10_backend.dll`.
- It taps `NuiSkeletonGetNextFrame` (flat export #17 — no vtable patching), reads the
  20-joint skeleton at ~30 Hz, runs a gesture recognizer, and synthesizes
  arrow / Enter / Esc keystrokes to the game window.
- Deployed to `E:\LegacyOfflinePC\Kinect10.dll`. Genuine runtime already renamed to
  `Kinect10_backend.dll` there; `Kinect10.dll.orig-backup` is the untouched original.

The game: DirectInput (dinput8), d3d11/dxgi, ANSI file paths, window title always
`"Legacy"`. Must run **windowed / borderless** (`config.xml` `FullScreen="0"`) or
exclusive-fullscreen hides the dev overlay. Crashes fairly often on its own.

## Current design — v0.8 "SWIPE" model (no engage state)

This replaced a long, failed "positional zone" model (engage-and-hold, hand offset from
a body origin drives arrows). That whole machine was **deleted**. The swipe model is
what worked back at milestone M3. Full vocabulary:

| Action | Gesture |
|---|---|
| **Left / Right** | Horizontal hand swipe (dominant hand). **Repeat:** after the swipe, fully **extend the arm straight out** and hold → accelerating auto-repeat until the arm relaxes. A plain swipe-and-hold is deliberately *not* enough — must be full extension. |
| **Up / Down** | Vertical hand swipe. One step only, **no** auto-repeat. |
| **Confirm (Enter)** | Dominant hand raised above shoulder-center + held roughly still ~1.8–2 s. |
| **Back (Esc)** | **Non-dominant** arm pointing **down-and-out to the side at ~45°**, held ~1.8–2 s. Must stay enabled — it's the escape hatch when Confirm fires by accident. |

**Gameplay auto-mute:** recognizer is silenced while a song plays (dance moves must not
drive the menu) but NOT in menus / title / song-select / coach-select. Signal is the
game's **file I/O**, not anything Kinect-side (call rates are body-dependent and useless):
menus continuously open `maps\<year>\<song>_pc.ipk` bundles; a song is 100% file-silent
for its whole duration (assets are preloaded from the `.ipk`). Detection = "same
`_pc.ipk` opened `songBurstCount` times in a row with nothing else between, then
file-quiet for `fileIdleGameplayMs`". Un-mutes on the next game-file open; clears
`g_songLoadTick` on the unmute transition to stop flap.

## What changed this session (built, synth 8/8, deployed at 03:41)

Two fixes for the user's last test feedback: *"sometimes down gets registered and as I'm
putting my hand to resting it would detect up"* and *"got muted again in song select …
by accidentally entering coach select of one coach and going back to song select"*.

### 1. Vertical swipe false-fires on the hand-to-rest transition
- `config.h`: `swipeYMin` `-1.15 → -0.95` (a dropping arm passes below the play zone);
  **new** `swipeVertXBand = 0.55` — a vertical swipe only counts while the hand is
  roughly *in front of* the body (`|ex| < band`). An arm recovering out to the side
  toward rest is outside the band now.
- `gestures.cpp`: the `vert` swipe-**start** condition, the `swAxis==2` **abort**
  condition, and the **fire** check all now also require
  `|ex| < swipeVertXBand && swipeYMin < ey < swipeYMax`.
- `config.cpp`: added `swipe_vert_x_band` ini key.

### 2. Gameplay mute mis-fires on coach-select bundle reopens
- `gameprobe.cpp` `Note()`: any *other* "interesting" file opening between two
  `_pc.ipk` opens now resets the run — added
  `else { s_count = 0; s_song[0] = 0; }` after the `IsSongBundle` block. Coach-select
  reopens the bundle a few times but interleaved with `.ckd` assets, so it can't reach
  a run of 6.
- `config.h`: `songBurstCount` `4 → 6`; `fileIdleGameplayMs` `6000 → 9000` (a real song
  is minutes of dead silence; a brief menu pause won't reach 9 s).

**Status:** compiled clean, `8/8` synth, DLL verified (8 ordinals / x86 / 173568 B),
copied to `E:\LegacyOfflinePC\Kinect10.dll`. **Not yet tested with the sensor by the
user.**

## Tuning knobs (current defaults, all overridable in kinectnav.ini as snake_case)

**Swipe:** `swipe_velocity 1.3` (torso/s min), `swipe_vx_ceiling 16.0` (jitter reject),
`swipe_distance 0.28` (net travel), `swipe_min_frames 2`, `swipe_axis_ratio 1.4`
(dominant axis must beat the other by this), `swipe_cooldown_ms 500`,
`swipe_settle_frames 3` (slow frames required before a new swipe), `swipe_settle_frac
0.7`, `swipe_y_min -0.95`, `swipe_y_max 1.10`, `swipe_vert_x_band 0.55`.

**L/R hold-to-repeat:** `post_swipe_ms 400` (window to catch the extend),
`arm_extend_frac 0.90` (|hand-shoulder| / bone-length sum, ~1.0 = straight),
`arm_relax_frac 0.80` (drop below → stop), `repeat_first_ms 430`, `repeat_min_ms 200`,
`repeat_accel_ms 22`.

**Confirm:** `confirm_dwell_ms 1800`, `confirm_raise_fy 0.05` (hand.y − shoulderC.y, torso),
`confirm_still_vel 1.2` (generous — an inferred hand jitters).

**Back:** `back_dwell_ms 1800`, `back_out_min 0.30` (sideways-away unit component),
`back_down_min 0.22`, `back_down_max 0.88` (above this = just a resting arm),
`back_still_vel 1.2`.

**Shared:** `dwell_grace_frames 20` (consecutive bad frames tolerated before a dwell
resets — grace resets to 0 on every *good* frame, so it's a true consecutive count),
`arm_after_frames 12` (ignore frames after re-acquiring a hand), `smooth_fast 0.5`,
`smooth_slow 0.15`.

**Mute:** `suppress_in_game 1`, `song_burst_count 6`, `song_burst_ms 2500`,
`file_idle_gameplay_ms 9000`, `gameplay_cap_ms 360000` (failsafe un-mute).

**Misc:** `enable 1`, `mirror 0`, `left_handed 0`, `enable_confirm 1`, `enable_back 1`,
`require_foreground 1`, keys `key_left/right/up/down/confirm/back` (VK codes),
`key_press_ms 40`, `trace 0`, `overlay 1`.
