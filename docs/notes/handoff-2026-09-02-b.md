### 2. `KinectNavigator-Setup.ps1` — live `kinectnav.ini` editor

Main window **Settings** panel (enabled once a valid game folder is picked; writes on change,
applies next game launch — no Install click needed):
`handedness` (Navigation hand), `mirror` (Reverse L/R), `enable_back`, `overlay` (HUD; ticking
into fullscreen offers a Yes/No to set `config.xml` `FullScreen="0"`).
**More settings…** dialog: 4 feel presets (reach `dpad_park_radius` / scroll speed
`dpad_repeat_*` / command reach `dpad_cmd_gate_radius` / hold time `dpad_cmd_dwell_ms` +
`dpad_back_dwell_ms`), clutch (`dpad_arm`), 6 key rebinds via a keypress-capture dialog,
"Reset keys". Plus "Open kinectnav.ini" (seeds from the example) and "Reset to defaults"
(deletes the ini). Ini writer uncomments-or-replaces-or-appends, collapses dup lines, ASCII.

### 3. DLL version resource + version-aware Update button

`src/KinectNavigator/version.h` (`KN_VER_MAJOR/MINOR/PATCH` = `0/9/0`) + `version.rc`
(`VS_VERSION_INFO`, `OriginalFilename` = `Kinect10.dll`) → `<ResourceCompile>` in the vcxproj.
`dllmain` banner logs `KinectNavigator v0.9.0 attached`. **Bump `version.h` in lockstep with
`CHANGELOG.md`, the release tag, and the `package.cmd` version arg.**
The installer reads `FILEVERSION` from the bundled shim vs. the installed `Kinect10.dll`:
newer bundle → **Update** (enabled); equal → **"Up to date"** (button disabled); older bundle
→ **Reinstall** + warning; unreadable (pre-resource shim) → **Update**. Title shows
`installer  v0.9`.

### 4. Localisation (12 languages) + portable config

LegacyDownloader's system ported: `dist/lang/*.json` flat key→string maps (105 keys), English
always loaded as the fallback layer, `{token}` interpolation, owner-draw flag + native-name
picker (same 12-flag base64 dict as LD), live re-label on switch (`Apply-Language`). Every UI
string is `T 'key'` now.
**All 12 languages fully translated** — en/fr/es by us; de it ja ko nl pt ru zh-Hans zh-Hant
Gemini-translated then a Gemini QA pass applied (Esc/Enter consistency, a nl "command mode"
mistranslation, ru Cyrillic units, ja wake-vs-launch wording, fr/es/nl button-width trims).
Prompts kept in `docs/notes/`: `gemini-translation-prompt-*` (do the 9),
`gemini-translation-eval-prompt-*` (QA all 12), `translation-brief-*`.
A mechanical check (key set/order, `{token}` parity, `\n` counts, `\"` escaping, `_meta`)
passes **12/12** — the script was ad-hoc PS+Python in the scratchpad, not in the repo; re-run
one if you touch a lang file.
**Portable:** game folder + `LANG` are remembered in a `config.txt` **beside the installer**
(the `%LOCALAPPDATA%` path was removed). Write is wrapped in try/catch → a read-only location
just means "not remembered". `dist/config.txt` is git-ignored. `package.cmd` bundles
`dist/lang/` into the release zip.
